# Unified Mentor Submission Checklist

The portal requires four valid HTTPS URLs and does not provide a direct file-upload field.

| Portal field | What it should point to | Status |
| --- | --- | --- |
| Github Repository Link | Public GitHub repository containing the project code and README | To prepare |
| Research paper link | Viewable PDF or document hosted on Google Drive | PDF prepared locally; Drive upload pending |
| Deployed project link | Live Streamlit/web-app URL, not a Google Drive file link | Deployment pending |
| Project Feedback video link | Your own 2-3 minute feedback video | Record and upload pending |

## Important access rule

Every URL must begin with `https://`. Test each link in a private/incognito browser window before submitting it.

## Google Drive plan

Upload the research paper PDF to Google Drive and set it to “Anyone with the link can view.” A project ZIP can also be uploaded as a backup, but a Drive file link is not a valid substitute for the live deployed-project URL.
